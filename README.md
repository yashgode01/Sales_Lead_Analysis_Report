# Sales Lead Analysis Report

## Project Overview

An Excel-based data analysis project designed to analyze sales leads, conversion performance, lead sources and key sales KPIs. The project transforms raw sales lead data into meaningful business insights using Excel.

## Objectives

* Analyze sales lead performance
* Identify high-performing lead sources
* Measure lead conversion rates
* Track important sales KPIs
* Identify patterns and trends
* Support data-driven business decisions

## Tools & Skills Used

* Microsoft Excel
* Data Cleaning
* Excel Formulas
* PivotTables
* Data Analysis
* KPI Analysis
* Dashboard Creation
* Business Insights

## Project Contents

* `Sales_Lead_Analysis_Report.xlsx` – Complete Excel analysis and dashboard
* `README.md` – Project documentation
* `PPT` – Project Powerpoint Presentation

## Key Analysis

The report includes analysis of:

* Total Leads
* Converted Leads
* Conversion Rate
* Lead Sources
* Sales Performance
* Lead Status
* Customer/Lead Segments
* Key Business KPIs

## Business Insights

The analysis helps identify:

* Which lead sources generate better conversions
* Which segments have higher conversion potential
* Overall sales lead performance
* Areas where sales teams can improve lead conversion

## Outcome

This project demonstrates practical Excel data analysis skills and the ability to convert raw sales data into actionable business insights through structured analysis and dashboards.
